## Problem

Portfolio cần một cách trình bày dự án và kỹ năng rõ ràng hơn, đồng thời vẫn giữ giao diện gọn gàng.

## Solution

Mình xây một cấu trúc portfolio tập trung, sử dụng card tái sử dụng, trang detail cho từng dự án và layout responsive.

## Details

# Website Portfolio

Đây là portfolio cá nhân được xây bằng Next.js, TypeScript và Tailwind CSS.

### Vai trò

Designer & Developer

### Công nghệ

- Figma
- Next.js
- TypeScript
- Tailwind CSS

### Mục tiêu

Tạo một portfolio tối giản, dễ đọc và dễ cập nhật bằng Markdown thay vì database.
