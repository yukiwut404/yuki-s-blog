# Portfolio Website

## Problem

The original experience needed a clearer way to present projects, skills, and case studies without overwhelming visitors.

## Solution

A focused portfolio structure with reusable cards, project detail pages, responsive layouts, and a local Markdown content system.

## Details

### Overview

This project is a personal portfolio built with **Next.js**, **TypeScript**, and **Tailwind CSS**.

The goal is to keep the content easy to edit while keeping the frontend lightweight and deployable without a database.

### What I did

- Designed the information architecture.
- Built the responsive UI.
- Created reusable project and blog components.
- Added Markdown-based project content.
- Prepared the project for static deployment.

### Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Markdown
